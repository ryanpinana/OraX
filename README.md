# OraX
OraX è un'applicazione multipiattaforma sviluppata con .NET MAUI che consente agli utenti di organizzare e gestire le proprie attività quotidiane attraverso un calendario moderno, intuitivo e personalizzabile.

Il progetto è stato realizzato come applicazione di gestione del tempo e degli impegni, offrendo strumenti per la pianificazione personale, la visualizzazione delle statistiche e la condivisione dei calendari con altri utenti.

# Requisiti per far funzionare il progetto:
 -Avere Visual Studio 2022
